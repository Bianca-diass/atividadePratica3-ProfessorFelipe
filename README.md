# Atividade Prática 3

Módulo em JavaScript composto por funções utilitárias para manipulação e análise de vetores (arrays).

## 📝 Descrição do Problema

O objetivo deste projeto é desenvolver um módulo em JavaScript que exporta três funções principais para processamento de vetores:

1. `media(vetor)`: Calcula e retorna a média aritmética dos valores contidos num vetor passado como parâmetro.
2. `menor(vetor)`: Localiza e retorna o menor valor presente no vetor.
3. `maior(vetor)`: Localiza e retorna o maior valor presente no vetor.

## 🚀 Tecnologias Utilizadas

* **JavaScript** / **Node.js**

## 📁 Estrutura do Projeto

* `funcoesVetor.js` - Ficheiro contendo a implementação das funções de manipulação de vetores.
